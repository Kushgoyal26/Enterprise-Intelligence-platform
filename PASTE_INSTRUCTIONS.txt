PATCH: Faster bulk data loading (batch inserts)
======================

Copy this file INTO your existing enterprise-intel-step2/enterprise-intel folder,
REPLACING the existing file:

  data/load_to_postgres.py    -> data/

No new pip installs needed (uses psycopg2.extras, already included).

TO RUN:
     python data/load_to_postgres.py

This will be dramatically faster (seconds instead of minutes) since it sends
all rows in a batch instead of one row at a time. Safe to re-run — the
schema.sql drops and recreates all tables each time, so it won't duplicate
the customers that already loaded.
